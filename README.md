# 그거

> "그때 보낸 **그거** 뭐였지?"

디스코드 1:1 DM을 제대로 검색하는 유저 설치형 봇입니다. DM 창에서 `/검색 youtube`를 입력하면, 나와 상대가 주고받은 메시지 중 그 글자가 들어간 **모든** 메시지를 찾아 디스코드 UI 그대로 보여줍니다. 링크 안의 단어, 두 글자 한국어, 유튜브 영상 제목, 첨부파일 이름까지 검색됩니다.

- 윈도우, 맥, 모바일 디스코드에서 모두 동작 (봇이라 설치할 프로그램 없음)
- 대화는 사용자별로 암호화해서 저장하고, 서버는 외부에서 들어오는 포트를 열지 않음
- AI 의미 검색(베타)은 서버 안에서 무료 모델로 처리

## 상태

설계 완료, 구현 전입니다. 전체 설계와 구현 순서는 [PLAN.md](./PLAN.md)에 있습니다.

## 개발 환경

```bash
npm install
cp .env.example .env   # 값 채우기
npm run gen-key        # 개발용 MASTER_KEY 생성
npm run demo           # 가짜 DM 데이터로 검색 체험 (디스코드 불필요)
npm test
npm run dev            # 봇 실행
```

Node.js 22 이상이 필요합니다.

## 주의

계정 토큰으로 DM 기록을 읽는 방식은 디스코드 이용약관에 어긋나며, 계정 정지 가능성이 있습니다. 가까운 사람끼리, 위험을 이해한 상태에서만 사용하세요.
